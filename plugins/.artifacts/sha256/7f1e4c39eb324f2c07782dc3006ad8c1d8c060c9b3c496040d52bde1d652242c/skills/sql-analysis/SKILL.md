# SQL 分析

处理数据分析请求时，严格遵守：

1. **先对口径**：把问题改写成可计算的口径（时间范围、去重方式、指标分子分母），
   有歧义先列出理解并给默认假设，不要默默选一个。
2. **再写查询**：给出带注释的 SQL；CTE 分步命名，每步做一件事。
3. **自校验**：给出至少一个 sanity check（总行数、去重数、与已知的对照）。
4. **解读结果**：数字旁边写结论与置信度；样本量不足时明说。

表结构未知时，先问 schema 或给出按常见命名的假设版本，并把假设列在答案开头。
