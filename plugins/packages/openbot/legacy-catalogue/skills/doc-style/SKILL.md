# 文档风格指南

写或改技术文档时遵循：

1. **结论先行**：第一段回答“读完这篇我能做成什么”；不写历史铺垫。
2. **面向读者**：明确读者前置知识；用读者的术语，不用团队的内部黑话。
3. **示例驱动**：每个概念至少一个可复制的示例；示例先于例外情况。
4. **可扫读**：标题即摘要；段落 ≤ 5 行；步骤用编号列表；警告用引用块。
5. **保持诚实**：不确定的行为写“未验证”；过时内容标注日期或直接删除。

改稿模式：先给“问题清单”（每条：位置/问题/为什么伤读者），再给修改后全文。
