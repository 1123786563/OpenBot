## 首页

发送区在首屏，明确说明自动选择 Bot 的规则，并提供直接指定 Bot 的入口。恢复发送和正在进行的会话使用各自的行列表，Explore Bots 放在会话相关内容之后。名单加载失败可就地重试，无访问权限时提示联系工作区管理员。窄屏验证覆盖输入后的发送按钮位置和目标链接。评审保留了对操作效率和帮助文案的扣分。发送按钮依旧是 28px，真实触屏与读屏体验待验证。

## 新建会话

收件人字段有持久标签，收件人列表与消息区相邻。列表展开时给消息区留出空间。未选收件人就按 Enter 或点击发送会在列表内提示，保留草稿并聚焦 To，键盘选中 Bot 后焦点进入消息区。深链接目标不可用时可清除原目标并重新选择。可重试的读取错误提供页内操作。模型清单读取失败时说明会使用默认模型。

收件人列表现在嵌入页面，展开时 Chromium 的无障碍树同时包含页面标题、消息输入和候选 Bot。Escape 关闭列表并留在收件人字段，再按 Tab 可到消息区。搜索后用方向键和 Enter 可以选中 Bot 并进入消息区。两页在 390 像素视口均有 16 像素左右留白，已消除原先新建会话的 5 像素横向溢出。真实读屏仍待验证。
