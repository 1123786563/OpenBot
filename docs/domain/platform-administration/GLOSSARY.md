# Platform Administration Glossary

## Deployment

One running OpenBot installation with its own infrastructure, configuration, database, model access, and edition.

## Model provider

A service that supplies the language model used by Bots or product services.

## Model availability

The set of models that the deployment can call successfully under its configured provider access.

## Enterprise setting

An organization-wide configuration controlled by an administrator.

## Identity provider

A service used to authenticate people into the workspace, including enterprise single sign-on providers.

## Migration

A versioned change that brings the deployment's persisted data into the current domain shape.

## Edition

The deployment mode that determines whether OpenBot runs as a personal installation or an organization workspace.
