# Memory, Learning, and Responsibilities Glossary

## Memory

Information retained so a Bot can use it across conversations. Memory may come from a source or be a personal memory belonging to a person.

## Memory source

A source of information that can be ingested, searched, or attached to a Bot's memory context.

## Learning

The process by which a Bot gains reusable behavior from demonstrations, reviews, or shared skills.

## Demonstration

A recorded example of a person showing how work should be performed.

## Learned skill

A reusable skill produced or approved through learning.

## Responsibility

A durable area of work assigned to a Bot. A responsibility has status, triggers, events, runs, and source bindings.

## Proactive check-in

A Bot-initiated review or suggestion that brings work or attention to a person without a new person message.

## Suggestion

A proposed proactive action that a person can start or dismiss.
