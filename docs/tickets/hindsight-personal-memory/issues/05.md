## What to build
用户确认并明确标为通用的偏好，可由同公司另一个获授权 Bot 在新会话语义找回。

## Acceptance criteria
- [ ] 确认后同步稳定文档身份；Hindsight 只返回命中与排序，Bot 只得到再次从 OpenBot 加载的已确认原文。
- [ ] 本人明确指定通用偏好后，同公司获授权的另一个 Bot 能跨会话召回；另一公司和另一用户不能召回。
- [ ] 无 OpenBot 当前记录、审核状态不符或依据映射缺失的远端结果被丢弃；Hindsight 的新提取事实或 reflect 文本不直接进入 Bot 上下文。
