## What to build
团队对话与连接来源形成的个人业务事实只在本人及当前有权的团队、Bot、来源范围内被使用。

## Acceptance criteria
- [ ] 确认来源受限记忆不使其成为通用偏好；同公司团队 B 的 Bot 不能使用团队 A 的业务事实。
- [ ] 来源停用、团队成员资格变化或 Bot 失去应用权限后，下一次召回立即排除相关记忆。
- [ ] 远端命中返回后到 OpenBot 加载前发生的撤权也被挡住；管理员身份不能读取员工内容。
