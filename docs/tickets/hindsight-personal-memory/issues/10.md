## Parent
Spec: #376

## What to build
用户能核查 Bot 使用的个人记忆，并直接从依据入口更正或遗忘。

## Acceptance criteria
- [ ] 涉及历史变化的回答展示可展开的已确认依据、来源和有效时间，不泄露当前无权的来源。
- [ ] 依据入口可发起更正或遗忘；操作后的下一次回答反映最新权限和事实。
- [ ] 依据缺失、失权或映射不完整时不展示推断内容，界面清晰表示不可用。

## Blocked by
- #383
- #386

## Verification
从 Bot 回答到 UI 操作做用户行为测试，并验证来源撤销后的依据不可见。

## Handoff notes
接口只返回 OpenBot 已审核且当前有权的依据；不将 Hindsight 原始观察交给前端。
事实源：父 Spec #376、仓库已批准的 Hindsight ADR、个人记忆领域术语与公司/团队多租户 Spec。只处理本票行为；前置票交付的接口以其验收结果和当前 Git 状态为准。接手前先核对前置票是否已验证并集成。完成或中断时记录变更范围、HEAD/未提交检查点、实际验证命令与结果、遗留问题；无提交授权时不要自行提交、推送或部署。
