## Parent
Spec: #376

## What to build
平台管理员可以运行并观察一套私有的 Hindsight 服务，服务只通过已批准模型网关处理个人记忆。

## Acceptance criteria
- [ ] 固定经过真实验证的 Hindsight 版本；服务 API 和控制台不直接暴露给终端用户或公司管理员。
- [ ] 模型调用经 OpenBot 已批准的网关；含内容模型追踪关闭，已结束操作载荷保留 1 天，受控备份保留不超过 30 天。
- [ ] 健康检查能区分服务可用、网关不可用和配置不合规，且不返回员工记忆内容。

## Blocked by
None (can start immediately)

## Verification
用真实自托管实例读取有效配置并运行网关调用与健康检查；保存镜像摘要、命令、响应和配置证据。

## Handoff notes
此票只证明服务与隐私运行基础，不把服务可用误报为已具备租户隔离或个人记忆召回。
