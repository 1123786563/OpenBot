## 验收标准

- [ ] AC1: 预览绑定码不创建授权，只有显式确认才提交；错误码、失效与重试状态保留。
- [ ] AC2: 模型选择保留领域 ID 与空值合同，复杂选项具备 id/textValue，禁用模型无法选择。
- [ ] AC3: 确认/撤销 pending 时防重复提交，成功状态与服务器一致，无凭据泄露。
- [ ] AC4: Modal/Select/ComboBox/Dropdown/Tooltip 公共封装完成迁移；本页未使用的能力以 H01 fixture 验证，不虚构页面功能。
- [ ] AC5: ESC/外部关闭、初始/返回焦点、嵌套遮罩、scroll lock 和短视口滚动正确；兼容性变化影响到的其他调用端一起修正。

## 实施任务草案

1. 迁移真实模型选择与授权列表路径，并接入公共浮层。
2. 按组件契约重写复杂 render 和受控值，保持原 mutation/query Interface。
3. 跑预览→取消/确认→列表→撤销，以及无效码、重复点击与失败重试。
