# [HeroUI H01] 建立 UI 迁移基线并验证 HeroUI 关键交互兼容

## 目标与依据

用可复跑证据确定迁移能保持现有能力，消除主题与组合接口的不确定性。

[父 Issue #443](https://github.com/1123786563/OpenBot/issues/443)；本地设计：`docs/specs/2026-10-19-heroui-ui-migration-design.md`。覆盖父级验收：A01, A02, A04, A05, A09。

Issue 正文自包含关键要求；设计全文也附在父 Issue 中，不能依赖尚未提交的文档链接才能开工。

## 依赖与角色

Blocked by：无代码前置；范围评审与实施授权仍是独立门槛。

建议序号 H01 是默认串行排期，不代表对所有前序节点都有硬依赖。

Owner：researcher；隔离 spike 由 frontend_implementer 承接；Validator：frontend_validator；独立 Review：reviewer。估算 1–2 人日，实施前按实测校准。

## 范围与所有权

- 计划专属 inventory / baseline / spike / 证据目录；隔离 spike 的最小测试与样式，不接入生产路由

## 验收标准

- [ ] AC1: 列清所有路由、26 个公共 UI 模块、相对/别名/动态导入、原生控件和 Base UI Props 调用；为每个文件确定迁移或保留归属。
- [ ] AC2: 核对并固定 HeroUI React/Styles 兼容版本，验证 React/Tailwind peer 依赖；不照抄 v2 配置。
- [ ] AC3: 真实浏览器验证 TanStack Link、Modal 内 Select、嵌套 Modal/Drawer、搜索与清空、旧新 token 同页、Questionnaire/Scroller render 组合。
- [ ] AC4: 右键菜单覆盖指针位置、Shift+F10/ContextMenu 键、触摸策略、关闭和焦点恢复；不满足时给出等价 Adapter 与成本，不删除能力。
- [ ] AC5: 保存两主题/中英文代表页截图、登录与聊天初始 JS/CSS gzip、既有测试失败与环境证据；形成最终契约和共存策略。

## 实施任务草案

1. 固定执行工作区与 BASE，扫描实际引用和当前版本。
2. 建立最小隔离 fixture，分别运行类型、样式和浏览器交互验证。
3. 记录每项通过/失败/阻塞、组件映射和回退方式；修正清单中的静态遗漏。

## Handoff

Consumes：无代码前置；范围评审与实施授权仍是独立门槛 所交付并已审查集成的 Interface/检查点；根 CONTEXT、适用 Spec/ADR。

Produces：版本锁定建议、契约矩阵、token 映射、浮层/右键菜单结论、基线与可复跑命令。

Verification：隔离 fixture 的 build/typecheck 与浏览器场景；现有代表测试的同版本基线。

测试遵守 ADR 0008 的 native/driven/engine 分层；Focus、portal、IME、定位和滚动必须有真实浏览器证据。复用同版本有效证据，只补缺失验证。

Resume：读取 manifest、当前 Task Brief/Ledger 与 Git，核验上游检查点；不重新派发已 verified 工作。阻塞项保留具体证据；缺陷回到对应实现任务，不由验证者修改源码。

## 组内共同约束

本组为设计与排期拆分，尚未授权实施。默认采用主 Web 应用 app/、保留现有 WorkBuddy 视觉；不包含独立 desktop 引导程序、OpenMuse/Bifrost 子模块和 Craft 生成模板的迁移。用户如选择整体重设计或扩大范围，应先更新父方案。

保留 React/Vite/TanStack/CopilotKit 及业务 API；保留 PromptArea、Streamdown、Recharts、Embla、问卷/消息滚动的专用行为。不得改变权限、业务范围、付款账户、错误事实或数据协议。

正式实施按根 AGENTS：执行工作区与 BASE → writing-plans → SDD → 独立验证/Review → OCR → 必要修复与复审。没有提交授权时使用未提交增量检查点；不因缺少提交停滞。标签 ready-for-agent 不是实施授权；当前方案仍待评审，暂不添加此标签。

共享 UI、主题、布局、locale 和 lockfile 同一时刻只有一个写入者。默认串行执行；依赖已关闭仍须核验已审查代码集成与验收证据。涉及其他 Issue 所有权的修正，先记录共享 Interface 变更，不并行覆盖文件。
