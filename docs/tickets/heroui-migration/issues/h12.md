## 验收标准

- [ ] AC1: 运行记录、数据集、评估详情/对比和导出状态的现有路径与深链接可用。
- [ ] AC2: 列表筛选、分页、排序、复杂表头/图表和异步状态保持，不为了换库改写查询或 Recharts。
- [ ] AC3: 运维连接失败/不可用/无权限/空数据明确；不把占位数据当成真实成功。
- [ ] AC4: 长表格横向滚动局限于容器，焦点和关键动作在窄屏/短屏可达。

## 实施任务草案

1. 消费 H06 Bot 详情壳迁移运行与评估页面。
2. 迁移观测与计算机运维动作，不改流和工具执行协议。
3. 用长数据、空数据和失败状态检验表格/图表和路由。

## Handoff

Consumes：[H03 #446](https://github.com/1123786563/OpenBot/issues/446)、[H06 #449](https://github.com/1123786563/OpenBot/issues/449) 所交付并已审查集成的 Interface/检查点；根 CONTEXT、适用 Spec/ADR。

Produces：运行/评估/运维业务迁移检查点。

Verification：已有运行评估和 ai-observability 测试；列表/图表/拒绝状态浏览器检查。

测试遵守 ADR 0008 的 native/driven/engine 分层；Focus、portal、IME、定位和滚动必须有真实浏览器证据。复用同版本有效证据，只补缺失验证。

Resume：读取 manifest、当前 Task Brief/Ledger 与 Git，核验上游检查点；不重新派发已 verified 工作。阻塞项保留具体证据；缺陷回到对应实现任务，不由验证者修改源码。

## 组内共同约束

本组为设计与排期拆分，尚未授权实施。默认采用主 Web 应用 app/、保留现有 WorkBuddy 视觉；不包含独立 desktop 引导程序、OpenMuse/Bifrost 子模块和 Craft 生成模板的迁移。用户如选择整体重设计或扩大范围，应先更新父方案。

保留 React/Vite/TanStack/CopilotKit 及业务 API；保留 PromptArea、Streamdown、Recharts、Embla、问卷/消息滚动的专用行为。不得改变权限、业务范围、付款账户、错误事实或数据协议。

正式实施按根 AGENTS：执行工作区与 BASE → writing-plans → SDD → 独立验证/Review → OCR → 必要修复与复审。没有提交授权时使用未提交增量检查点；不因缺少提交停滞。标签 ready-for-agent 不是实施授权；当前方案仍待评审，暂不添加此标签。

共享 UI、主题、布局、locale 和 lockfile 同一时刻只有一个写入者。默认串行执行；依赖已关闭仍须核验已审查代码集成与验收证据。涉及其他 Issue 所有权的修正，先记录共享 Interface 变更，不并行覆盖文件。
