**Produces（本 Ticket 交付给下游的契约）**

- 防低报语义：客户端提交的时长/大小元数据与实际测量不一致时，以测量值为准并记录异常
- 篡改尝试可审计（差异值、来源、时间），供 22.2 旁路核查引用
- 结算按可信测量与真实 usage，二者冲突时进入 unknown 而不是取较小值

## Implementation steps

1. 比对客户端声明与服务端测量，不一致时以测量值计价并记录异常事件
2. 确认结算不以客户端声明为依据；真实 usage 与测量冲突时标记 unknown
3. 把差异记录写入审计，便于发现系统性低报
4. 先写失败测试：伪造短时长元数据 → 按实际测量计费并产生异常记录
