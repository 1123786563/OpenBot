## What to build

工作台直接使用当前登录身份，无需绑定码，且授权范围与外部 Bot 区分。

## Acceptance criteria

- [ ] 已登录用户在工作台获得隐式授权，无需绑定码
- [ ] 未登录时不存在任何隐式授权
- [ ] 隐式授权与外部授权可区分且都可撤销
- [ ] 隐式授权不授予公司内容访问，也不绕过积分准入

- 组 04 缝合点：管理员登记 Bot → 外部用户绑定授权 → 用户撤销，端到端可演示

## Implementation steps

1. 为 builtin 工作台 Bot 生成隐式授权，主体来自当前登录会话
2. 隐式授权与外部授权共用 AccessGrant 模型，但标记不同来源，便于审计与撤销
3. 确认隐式授权不绕过 06.2 的准入重验，也不自动获得公司内容访问（由 09.3 保证）
4. 先写失败测试：未登录无隐式授权；隐式授权可被撤销；来源标记正确
