## Implementation steps

1. 复用现有凭据加密存储新增一种网关管理凭据类型，禁止把明文写入配置表或日志
2. 提供管理员写入/轮换接口：写入成功只返回脱敏状态（是否存在、最近更新时间、指纹后 4 位）
3. 提供内部解密入口并限定调用方为服务端受信代码路径，不经任何 HTTP 响应返回
4. 确认所有日志与错误信息路径对凭据脱敏（包括上游 4xx/5xx 响应体不回显）
5. 先写失败测试：读取接口与日志中都不出现明文；轮换后旧引用不可用
