## Contracts

**Produces（本 Ticket 交付给下游的契约）**

## Implementation steps

1. 核对上游编辑定价是否对输入图像/掩码收费，映射到 PriceSnapshot
2. 扩展上限换算，把输入成本与输出规格成本合并计算
3. 输入不可确定（如动态生成掩码）时判证据不足并拒绝
4. 先写失败测试：带输入图像的编辑请求上限包含输入成本
