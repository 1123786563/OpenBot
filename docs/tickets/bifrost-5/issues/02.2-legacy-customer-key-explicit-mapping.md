**Produces（本 Ticket 交付给下游的契约）**

- 显式映射记录：每个存量 externalCustomerId 归入 legacy_deployment 账户或标记 unknown_owner

## Implementation steps

1. 枚举存量 Grant 与台账中出现的 externalCustomerId，按显式规则归类，禁止用字符串前缀或命名猜测账户类型
2. 无法确定归属的记录标记 unknown_owner 并隔离，保留原值不删除
3. 迁移写成幂等：重复执行不新增映射、不改写已有归类
4. 输出报告：各类数量、隔离数量、未处理项；不复制余额、不分摊到个人
5. 先写失败测试：混合数据 fixture 下迁移幂等、未知归属隔离、公司历史不被改写

- 本 Ticket 是业务完整切片，接口、数据库变更、授权、必要用户/管理状态和行为测试同时完成；只修改本切片涉及模块，不能顺便实施其他 Ticket。
- 领取前核验 Blocked by 各任务已验证并集成到当前工作区，读取其实际交付契约；依赖未完成不造假桩冒充已集成。任务内 provider fake 仅为测试，不得成为生产降级。
- 执行按仓库要求建立或核验工作区，记录原始 BASE 和用户改动，先 writing-plans 再 SDD/TDD；按稳定接口分派前后端及跨语言任务。没有提交授权时使用未提交检查点，不自动提交、推送或改父 Issue。
