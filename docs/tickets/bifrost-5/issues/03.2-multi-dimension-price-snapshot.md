## Implementation steps

1. 定义完整计费维度集合，逐一映射上游定价字段，映射不到的维度记 unknown
2. 以精确十进制/整数存储价格，禁止浮点近似
3. 每个快照记录版本、成功同步时间、来源与当时 rateVersion
4. 快照不可变：更新只新增版本，历史版本可被结算路径引用
5. 先写失败测试：多维 datasheet fixture 往返一致；缺维度为 unknown；改写历史快照被拒绝
