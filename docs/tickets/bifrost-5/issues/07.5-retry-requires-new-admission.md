## Implementation steps

1. 确认 fallback/重试路径为每次真实尝试生成新 attemptId 并重新走 Reserve
2. 拒绝任何复用旧标识进行第二次派发的路径
3. 记录重试链（原 attempt 与新 attempt 的关联）
4. 先写失败测试：触发一次重试，断言产生两次预留与两条承诺
