# 按个人用户归属积分，按 Bot 授权隔离模型凭据

OpenBot 用户是模型消费与积分余额的归属主体，每个“用户 × Bot 授权”分别发放有有效期的 Bifrost 虚拟 Key，所有 Key 共同消费同一用户余额。首次模型调用或授权时按需创建关联治理主体，不要求该主体具备 Bifrost 登录身份。

外部 Bot 从 OpenBot 获取凭据和模型信息后直接调用 Bifrost。这允许独立撤销某个 Bot 的访问并区分消费来源，但使 OpenBot 现有模型调用门控无法覆盖直连请求；严格防超支必须在直连路径中补足共享预留与结算机制。该机制、Bifrost 扩展范围及故障处理尚待设计，不能用原生周期预算替代个人积分余额。

拒绝的替代方案是所有用户共享部署余额、每用户所有 Bot 共用一个 Key，以及每个 Key 复制用户的全部积分额度。前两者无法满足用户确认的个人归属和独立撤销，后者会重复授予可消费额度。

依据：`docs/specs/2026-10-14-bifrost-integration-design.md` 中用户确认的 Q1–Q9。本 ADR 只确认身份、凭据粒度及调用路径，不代表完整方案已批准实施。
