# 由独立服务统一拥有个人长期记忆

为供 OpenBot 之外的应用和 Bot 复用，独立记忆服务统一拥有个人长期记忆原文、候选与审核、更正、来源、遗忘及相关历史的唯一写入权。OpenBot 与其他接入应用通过服务 API 操作，不再直接写记忆服务拥有的表。Hindsight 作为服务内部的检索与推理实现。

选择完整记忆业务服务，而非仅将已有检索能力包装为远端 API，使各应用复用同一套记忆生命周期规则。代价是身份、来源权限和原有同库依赖需要明确的远端合同，以及迁移和故障处理方案。

应用之间默认隔离记忆；同一人的身份关联本身不授予跨应用读取权。本人明确授权指定范围后才允许跨应用读取，且不扩大原有公司及来源权限。通用个人偏好也不因接入同一服务而自动向其他应用开放。

身份统一采用 Better Auth。OpenBot、记忆服务与自有应用共用同一套身份中心，同一个人使用同一用户身份；外部应用保留自己的账号，经本人验证后关联，不凭邮箱或同名自动合并。共用身份不自动授予记忆访问权；登录、会话验证及跨域协议尚待设计。本选型不授权另建可独立修改的 OpenBot 身份或成员目录，OpenBot 既有目录方向仍见 [ADR 0011](0011-better-auth-identity-and-membership-authority.md)。

接入应用须先完成登记，并获得本人独立授予的内容提交和本应用已确认记忆读取委托；采集和读取可分别撤销。应用服务身份不代替本人委托，本应用委托不授予读取其他应用记忆的权利，后者另需逐条共享授权。具体凭据、签发与验证协议尚待设计。

首版由本人选择具体记忆，授权指定应用只读，可随时撤销；新增记忆不自动加入共享范围。接收应用不能凭此授权更改或删除原记忆，可经正常审核流程提交新候选。相比分类持续共享，这种方式让本人明确掌握每次共享的内容，代价是增加手动选择；分类持续共享及自动包含未来记忆留待后续设计。

共享绑定本人确认的内容版本：更正立即停止向接收应用返回旧版本，新版本须再次授权，派生记忆也须单独授权。这样本人能控制实际外发内容，代价是更正后需要重新选择共享。

撤销的保证包括服务阻止后续读取，以及要求接入应用清理受其控制的缓存和副本。对已进入聊天记录、模型上下文或其他系统的内容，分别记录处理范围和清理结果；界面区分“已停止共享”与“应用侧清理完成”，不宣称已收回全部外发内容。清理回执、在途请求与核验机制尚待设计。

业务来源的当前权限由来源应用裁决，记忆服务在返回来源受限内容前在线核验；无法核验则不返回该内容。无外部来源限制的个人记忆由记忆服务按自身授权规则判断。此选择避免复制各应用的业务权限体系，代价是来源应用故障时相应记忆暂不可用。核验接口、在途撤权竞态与返回时点的具体保证尚待设计，不凭此方向宣称已实现即时撤权。

记忆服务提供统一管理界面，供本人审核候选、更正、遗忘和管理共享授权，各应用通过跳转或嵌入接入。相比各应用各自实现管理入口，此选择统一用户控制与审核体验，代价是各应用需集成这一入口；具体认证和嵌入合同尚待设计。

用户进一步指定 Bun/Hono、PostgreSQL、React 与 HeroUI。管理界面同时支持独立访问与从 OpenBot 菜单进入、保留 OpenBot 侧栏的内容区内嵌。统一 Better Auth 身份中心独立部署并提供 OIDC，OpenBot 和记忆服务作为客户端；登录在顶层通过统一身份中心跳转完成，登录后的内嵌展示不赋予 OpenBot 记忆所有权。

相比简单外链，内嵌可保留工作台体验，代价是明确宿主 Origin、路由、浏览器会话和登录回跳合同；具体 iframe、代理或其他承载技术仍属待评审实现建议。独立身份中心使公共登录能力不依赖 OpenBot 业务进程，代价是新增独立部署、提供方能力和身份连续性验证；不自动授权迁移身份数据或重建用户。

来源应用负责连接及原始内容获取，向服务提交经授权的片段及来源信息。服务统一提取候选、识别重复与冲突，并交本人审核，避免各应用分别定义记忆形成规则。片段保留、异步处理、重复提交及主动“请记住”等既有例外的具体合同尚待明确，不据此新增绕过本人审核的路径。

片段处理采用异步交互：可靠接收后返回可查询状态，后台提取候选，再交本人审核；界面区分已接收、处理中、待审核与已确认。提取不阻塞应用对话，代价是候选不会立即可用。普通事实的主动“请记住”直接确认例外继续保留，具体受信认证、幂等与接收合同尚待设计。

原始片段属于临时处理材料，处理结束后一天内从活跃存储删除；排队最多保留 30 天，超时显示已过期。候选最小依据另按记忆保留规则管理，备份清除仍有单独保留与验证要求。这限制片段长期积累，代价是过期任务需重新提交。

首版由服务运营方承担候选提取、索引与推理的模型费用，按应用和个人设置预算上限并记录分应用用量，暂不建设接入应用收费系统。预算不足时保留待处理状态并向用户展示，不将未处理内容标记为已记住。具体受管模型接入与预算执行合同尚待设计。

服务直接连接可配置的模型网关，以自身服务身份调用模型、执行预算控制并独立记录用量与处理任务，不通过 OpenBot 的业务 API。网关基础设施可共用。此选择使其他应用使用记忆服务无需依赖 OpenBot 应用在线，代价是服务须维护自己的受管调用与预算执行合同。

记忆服务整体不可用时，普通对话可继续并明确本次未使用个人记忆；必须依赖记忆的任务提示暂不可执行。故障期间暂停记忆读写，不使用未经当前授权核验的旧副本；恢复后重试已可靠接收的待处理任务。该选择保留普通对话可用性，代价是故障期间缺少个性化上下文；不替代 Hindsight 单独故障时在服务内部进行已授权本地降级的既有约束。

服务采用独立仓库、独立部署和独立业务数据库，OpenBot 经客户端适配器接入，统一身份中心作为共同依赖。数据库可共用基础设施，各服务独立拥有业务数据与迁移。相比保留在 OpenBot 仓库内，此选择便于多应用复用及独立发布，代价是维护独立构建、版本兼容与集成验证。

首版不迁移 OpenBot 现有个人记忆。接入时删除 OpenBot 原有本地记忆实现、旧引擎记忆路径与回退逻辑，统一接入新服务；新服务不可用时也不恢复旧记忆路径。删除实现不自动包含删除旧数据；旧文档标记替代关系并保留决策历史。此变更不取消本轮确认的审核、授权、来源限制与遗忘规则。

本决定局部替代 [ADR 0005](0005-self-hosted-hindsight-for-personal-memory.md) 的记忆权威归属，保留其审核、来源约束、更正、遗忘、暂停及检索结果核验等要求；这些规则在目标架构中由记忆服务及待明确的应用合同共同落实。本决定不证明迁移已发生，也不授权产品代码实施或生产迁移。

设计访谈依据见[决定记录](../plans/2026-10-30-independent-memory-service-design.md)，完整合同与验收见[Spec v3](../specs/2026-10-30-independent-memory-service-design.md)。用户已在 Q26 批准该 Spec 作为实施计划依据，其批准元数据独立记录，不自动扩大为实施或部署授权。
