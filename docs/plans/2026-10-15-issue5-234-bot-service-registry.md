## Design decisions

- New table `bot_services`: `bot_id` text PK（全局唯一、不可复用——无删除路径，主键即唯一约束）, `display_name`, `kind` enum `bot_service_kind('builtin','external')`, `capabilities` `bot_service_capability[]`（受限枚举 chat/image/audio/embedding/realtime/async，CHECK 非空且无重复）, `status` enum `bot_service_status('active','disabled')` default active, `registered_by`, `disabled_at`, `disabled_by`, `created_at`, `updated_at`。No FK to `users`（登记是部署级事实，与审计行同样保留操作者 id 而非级联）。
- Module `server/src/bot-services/{store,routes}.ts`:
  - `createBotServiceStore(database, auditStore)` → `register/edit/disable/getBotService/listBotServices` + `BotServiceRefusedError{status,code}`。
  - Duplicate botId ⇒ unique-violation caught ⇒ refused 409（并发下由 PK 兜底，确定性失败注入测试覆盖并行双登记）。
  - `disable` 幂等语义：再次停用拒绝 409（明示状态，而非静默成功）。
  - 注册/编辑/停用各写一条审计：`bot_service.registered/edited/disabled`，targetType `bot_service`，payload 含变更前后（编辑 from/to），不含任何凭据材料。
  - 登记不写 `credentials`、不写任何授权/积分表 —— 由测试断言（credentials 行数不变）。
- Routes `createBotServiceAdminRoutes({requireUser, store})` mounted at `/api/admin/bot-services` only when store provided: `GET /`(admin, list) `GET /:botId` `POST /`(register) `POST /:botId`(edit) `POST /:botId/disable`。非管理员 403、未登录 401、输入非法 400、botId 不存在 404。
- app.ts: append `botServiceStore?: BotServiceStore` as the LAST positional param（仓库惯例）；index.ts 装配 `createBotServiceStore(database, bootAuditStore)`。
- Admin UI: `app/src/routes/_authed/admin/bot-services.tsx` + `app/src/lib/bot-services/{queries,mutations}.ts` + sidebar(`access` 组) + admin overview card（与 sidebar 同组同序，页面注释要求两侧一致）+ zh-CN/en `admin.json` i18n + regenerate `routeTree.gen.ts`。
