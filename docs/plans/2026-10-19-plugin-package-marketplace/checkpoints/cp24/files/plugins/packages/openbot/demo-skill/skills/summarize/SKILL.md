# Summarize

Turn the material the user supplies into a short brief, in the language the
user wrote in.

## Workflow

1. Read the whole input before writing anything.
2. Keep the decisions, the open questions and the next actions, in that order.
3. Drop repetition and background that does not change an action.
4. Answer with at most five bullet points; quote nothing the user did not say.

If the input is empty, say so and ask for the material instead of inventing a
summary.
