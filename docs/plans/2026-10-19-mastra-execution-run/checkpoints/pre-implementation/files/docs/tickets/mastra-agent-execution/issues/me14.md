## Parent

## What to build

运维能清楚处置每个在途/暂停任务，在维护窗口单写切换，并在故障时保留新消息和结果回退。

## Acceptance criteria

- [ ] 切换前核对全部运行入口、旁路历史 reader、活跃 writer/lease 与暂停清单；缺项不得 apply。
- [ ] 停止目标范围新准入并排空旧执行；已终结记录只读，可兼容暂停转换并跨进程演练，不兼容暂停选择旧路排空或明确隔离/重新发起。
- [ ] 记录版本/写入 fence，验证导入后才切 engine/backend；任何时刻同范围不能有两套 writer，客户端不能切引擎。
- [ ] 旧 owner、过期 lease 或旧 worker 在切换后不能发起新外部操作、追加成功或覆盖新状态。
- [ ] 切换后出现新消息/快照再 rollback，仍保留完整新历史与操作 receipt；仅回退支持当前数据的兼容版本，不直接指回旧库。
- [ ] 如果无法安全回退，停在维护状态并展示可诊断原因，不删除新数据或自动重复外部写操作。
- [ ] 所有 apply/rollback 只在授权 fixture 演练；生产维护命令与责任人/恢复门槛形成可审查 runbook，生产执行另获授权。
