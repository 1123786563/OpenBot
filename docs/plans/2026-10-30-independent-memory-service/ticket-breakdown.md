# #713 纵向 Ticket 拆分草案

来源：GitHub #713，已批准 Spec v3；状态：用户已批准拆分，已发布子 Issue；序号为草案标识，不是 GitHub Issue 编号。

## 01 独立身份中心登录

**阻塞于：** 无

**交付：** 独立身份中心支持用户登录及两个应用的 OIDC 接入。

- [ ] 两个已登记应用通过 PKCE 登录；错误回调、重放和错误受众被拒绝
- [ ] OpenBot 业务进程停止后身份中心仍可独立登录

## 02 保留现有用户身份接入统一登录

**阻塞于：** 01

**交付：** 已有用户登录后继续访问本人原有业务资源。

- [ ] 稳定主体和历史资源引用保持连续；同邮箱不自动合并
- [ ] 停用用户不可通过登录恢复；公司团队权限不因登录扩大

## 03 接入应用登记与本人委托

**阻塞于：** 01

**交付：** 用户能分别允许应用采集记忆和读取本应用记忆。

- [ ] 应用登记不代表用户授权；采集和读取可分别撤销
- [ ] 伪造用户或其他应用身份不能获取授权

## 04 从授权内容提交候选

**阻塞于：** 03

**交付：** 应用提交内容后，用户能看到可靠接收和待处理状态。

- [ ] 同一请求重试不重复创建任务；接收失败不显示成功
- [ ] 撤销采集或来源后待处理任务不可继续形成候选

## 05 审核候选形成个人记忆

**阻塞于：** 04

**交付：** 用户在独立界面确认、编辑或拒绝候选并查看来源。

- [ ] 未审核或拒绝的候选不在任何召回路径可见
- [ ] 候选去重和冲突不覆盖已确认事实

## 06 明确记住与敏感内容保护

**阻塞于：** 05

**交付：** 用户明确要求记住普通事实时直接确认，敏感内容得到保护。

- [ ] 本人明确请求需可验证；应用和模型不能冒充
- [ ] 密码令牌不保存；敏感信息遵循额外审核

## 07 来源权限受控的记忆召回

**阻塞于：** 05

**交付：** 应用仅能召回本人当前有权使用的记忆。

- [ ] 按应用、公司、团队、来源及 Bot 范围检查
- [ ] 来源不可用或失权时阻断相关内容；不泄露未授权内容

## 08 暂停学习与暂停使用

**阻塞于：** 05,07

**交付：** 用户可独立暂停新记忆学习或已有记忆使用。

- [ ] 暂停学习阻断后续采集和待处理形成
- [ ] 暂停使用立即阻断召回，恢复不改变原有授权

## 09 更正记忆及历史有效时间

**阻塞于：** 05,07

**交付：** 用户可以更正记忆并在历史问题中查看适用事实。

- [ ] 保留更正历史及有效时间；当前问题使用当前版本
- [ ] 历史读取仍检查当前本人和来源权限

## 10 派生记忆与依据审核

**阻塞于：** 05,07

**交付：** 用户可以审核有来源依据的综合判断。

- [ ] 仅以已确认且有权使用的依据形成候选
- [ ] 派生继承全部依据限制；本人确认前不召回

## 11 逐条授权其他应用只读

**阻塞于：** 07

**交付：** 用户选择具体记忆内容版本，授权指定应用只读。

- [ ] 其他应用默认不可见；新增记忆不自动共享
- [ ] 授权不允许修改或删除；更正或派生需重新授权

## 12 撤销共享并跟踪应用副本清理

**阻塞于：** 11

**交付：** 用户撤销共享后，服务停止读取并追踪接收应用的清理。

- [ ] 在途读取按交付前核验合同处理；通知可靠重试
- [ ] 区分已停止共享、部分清理与有证据的完成；不能承诺追回已交付内容

## 13 遗忘记忆与来源撤销

**阻塞于：** 07

**交付：** 用户可遗忘记忆或撤销来源，并跟踪相关清理。

- [ ] 立即阻断原始及派生内容，清理索引、依据和副本
- [ ] 临时来源故障不当作永久撤销；重新连接不复活已撤销内容

## 14 记忆处理预算与用量

**阻塞于：** 04

**交付：** 运营方可按应用及个人控制后台处理费用。

- [ ] 并发任务不突破预算；预算不足显示待处理
- [ ] 实际费用未知不盲目释放预留或重复调用

## 15 内容保留期限与恢复

**阻塞于：** 04,13

**交付：** 临时内容按期限清理，恢复后已撤销内容不会复活。

- [ ] 处理完成后一天内清除原始片段，排队和候选最多 30 天
- [ ] 备份不超过 30 天；恢复先重放遗忘和撤销

## 16 服务故障与授权降级

**阻塞于：** 07

**交付：** 记忆不可用时应用明确降级，避免使用未经授权的旧数据。

- [ ] 服务故障普通对话继续并提示，依赖记忆的任务暂停
- [ ] 仅检索服务故障时可从权威数据按相同权限降级

## 17 OpenBot 来源授权与记忆接入

**阻塞于：** 02,07

**交付：** OpenBot 对话、频道和后台任务使用新服务并保留来源权限。

- [ ] 可信来源范围绑定本人、公司、团队、Bot 和接收应用
- [ ] 浏览器和无人值守入口执行同一权限及来源规则

## 18 OpenBot 内嵌记忆管理

**阻塞于：** 02,05

**交付：** 用户从菜单进入同一记忆界面并保留 OpenBot 侧栏。

- [ ] 独立站与内嵌站使用同一身份和记忆
- [ ] 顶层完成 OIDC 登录并返回，刷新、退出和会话失效可用

## 19 切换全部入口并移除旧记忆路径

**阻塞于：** 08,09,10,12,13,14,15,16,17,18

**交付：** 所有实际入口完成切换，旧记忆运行及回退路径退出。

- [ ] 旧数据不迁移或删除，旧后台任务不能继续写入
- [ ] Bot 生命周期及其他非记忆职责保持正常

## 20 跨应用端到端验收

**阻塞于：** 06,08,09,10,12,13,14,15,16,19

**交付：** 在真实隔离环境贯通身份、服务、OpenBot 和外部应用。

- [ ] 覆盖父 Issue A01–A19，包括撤权竞态、预算、恢复和两种界面入口
- [ ] 记录运行版本、测试结果、清理证据及未验证项
