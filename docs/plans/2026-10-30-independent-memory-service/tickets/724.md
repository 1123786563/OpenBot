# 逐版本只读共享 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 #724 的逐版本只读共享，满足下列原 Issue 全部验收。

**Architecture:** 共享绑定本人、确定版本和已登记接收应用；交付仍执行读取委托与来源检查。 身份、来源与任务事实由各自权威拥有；跨服务调用使用具名合同，不直接读取其他服务数据库。

**Tech Stack:** 拟建 MEMORY：Bun、Hono、PostgreSQL、React、HeroUI；测试执行器和依赖须在建库时配置。

**Spec:** [已批准 v3](../../../specs/2026-10-30-independent-memory-service-design.md) §§5–11；[ADR 0012](../../../adr/0012-independent-personal-memory-authority.md)；[合同](../contracts.md)；[MEMORY 分册](../memory.md)。

## Global Constraints

- MEMORY 和 IDENTITY 为拟建独立仓库，以下相对路径均为拟建 MEMORY 路径，不代表文件已存在；独立 PostgreSQL，应用不得直接写表。
- 已登记应用、本人身份、委托、版本共享、当前来源资格分别核验；候选不可召回。来源无法核验不等于空结果。
- 不迁移旧记忆；不凭邮箱合并身份；不以服务密钥或模型输出冒充本人。提交、生产迁移、部署及外部写入不由此计划授权。
- 完整片段处理结束一天内清除，排队和未审核候选最多 30 天，备份不超过 30 天；记忆模型调用受预算控制。
- 原生阻塞：#720。阻塞任务须 verified 且产物进入实际工作区；fixture 只能验证本票行为，不能证明真实集成完成。

## Review Focus

- `owner_shares_exact_version`：本人选择已确认版本和登记应用，保存后界面展示准确版本及应用；其他主体不可共享。
- `default_deny_and_scoped_read`：其他应用默认无正文；仅指定应用且读取委托、共享及来源同时有效才返回指定版本。
- `share_is_read_only`：接收应用修改、删除和伪造本人共享均拒绝；单凭服务密钥无法创建共享。
- `new_versions_never_inherit`：新记忆、更正后新版本、新派生均未自动共享；旧版本更正后不再返回。
- `share_obeys_source_boundaries`：逐一更换公司、团队、来源或未知接收应用并模拟来源失败，受限内容不返回。
