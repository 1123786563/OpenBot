# 遗忘与来源撤销 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 #726 的遗忘与来源撤销，满足下列原 Issue 全部验收。

**Architecture:** 本人操作原子持久撤销和清理意图，传播派生依赖并取消未完成任务；清理异步可重试。 身份、来源与任务事实由各自权威拥有；跨服务调用使用具名合同，不直接读取其他服务数据库。

**Tech Stack:** 拟建 MEMORY：Bun、Hono、PostgreSQL、React、HeroUI；测试执行器和依赖须在建库时配置。

**Spec:** [已批准 v3](../../../specs/2026-10-30-independent-memory-service-design.md) §§5–11；[ADR 0012](../../../adr/0012-independent-personal-memory-authority.md)；[合同](../contracts.md)；[MEMORY 分册](../memory.md)。

## Global Constraints

- MEMORY 和 IDENTITY 为拟建独立仓库，以下相对路径均为拟建 MEMORY 路径，不代表文件已存在；独立 PostgreSQL，应用不得直接写表。
- 已登记应用、本人身份、委托、版本共享、当前来源资格分别核验；候选不可召回。来源无法核验不等于空结果。
- 不迁移旧记忆；不凭邮箱合并身份；不以服务密钥或模型输出冒充本人。提交、生产迁移、部署及外部写入不由此计划授权。
- 完整片段处理结束一天内清除，排队和未审核候选最多 30 天，备份不超过 30 天；记忆模型调用受预算控制。
- 原生阻塞：#720。阻塞任务须 verified 且产物进入实际工作区；fixture 只能验证本票行为，不能证明真实集成完成。

## Review Focus

- `forget_and_revoke_block_dependents`：遗忘或来源撤销事务提交后，原始记忆及所有派生立即不可召回，远端清理可尚未完成。
- `revocation_fences_inflight`：读取在检索后 barrier 暂停，撤销后继续，最终重验权威状态和来源且不交付。
- `cleanup_tracks_all_scopes`：来源撤销取消未完成提取，追踪索引活跃文档、观察、依据和外发副本；遗忘也追踪索引及派生。
- `temporary_failure_is_not_revocation`：来源超时或拒绝时阻断访问但不写永久撤销或删除；恢复资格后可按当前授权读取。
- `reconnect_does_not_resurrect`：重启及重连或成员恢复后旧内容仍阻断；新采集须新授权和正常审核。
