# 暂停学习与使用 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 #721 的暂停学习与使用，满足下列原 Issue 全部验收。

**Architecture:** 独立持久化两项本人控制，处理开始与候选提交前重验 learning，召回交付前重验 usage。 身份、来源与任务事实由各自权威拥有；跨服务调用使用具名合同，不直接读取其他服务数据库。

**Tech Stack:** 拟建 MEMORY：Bun、Hono、PostgreSQL、React、HeroUI；测试执行器和依赖须在建库时配置。

**Spec:** [已批准 v3](../../../specs/2026-10-30-independent-memory-service-design.md) §§5–11；[ADR 0012](../../../adr/0012-independent-personal-memory-authority.md)；[合同](../contracts.md)；[MEMORY 分册](../memory.md)。

## Global Constraints

- MEMORY 和 IDENTITY 为拟建独立仓库，以下相对路径均为拟建 MEMORY 路径，不代表文件已存在；独立 PostgreSQL，应用不得直接写表。
- 已登记应用、本人身份、委托、版本共享、当前来源资格分别核验；候选不可召回。来源无法核验不等于空结果。
- 不迁移旧记忆；不凭邮箱合并身份；不以服务密钥或模型输出冒充本人。提交、生产迁移、部署及外部写入不由此计划授权。
- 完整片段处理结束一天内清除，排队和未审核候选最多 30 天，备份不超过 30 天；记忆模型调用受预算控制。
- 原生阻塞：#718、#720。阻塞任务须 verified 且产物进入实际工作区；fixture 只能验证本票行为，不能证明真实集成完成。

## Review Focus

- `independent_pause_controls`：分别设置与恢复 learning/usage，读取两值并断言另一值不变。
- `paused_learning_blocks_queued_and_new`：暂停后提交与已领取任务均不产生候选；在候选提交 barrier 前暂停也不产生。
- `paused_usage_blocks_all_recall_paths`：原应用、共享应用、索引命中和 Hindsight 故障降级均返回无正文；交付 barrier 前暂停亦阻断。
- `resume_preserves_grants`：撤销采集、读取、共享、来源中各一项后暂停并恢复，授权记录未变且对应请求仍拒绝。
- `pause_requires_owner_session`：服务密钥、伪造 userId 及其他本人会话均不能更改状态，真正本人可更改。
