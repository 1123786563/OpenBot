# 撤销共享与副本清理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 #725 的撤销共享与副本清理，满足下列原 Issue 全部验收。

**Architecture:** 同事务撤销共享并记录通知意图；发送与回执幂等重试，按实际控制范围报告结果。 身份、来源与任务事实由各自权威拥有；跨服务调用使用具名合同，不直接读取其他服务数据库。

**Tech Stack:** 拟建 MEMORY：Bun、Hono、PostgreSQL、React、HeroUI；测试执行器和依赖须在建库时配置。

**Spec:** [已批准 v3](../../../specs/2026-10-30-independent-memory-service-design.md) §§5–11；[ADR 0012](../../../adr/0012-independent-personal-memory-authority.md)；[合同](../contracts.md)；[MEMORY 分册](../memory.md)。

## Global Constraints

- MEMORY 和 IDENTITY 为拟建独立仓库，以下相对路径均为拟建 MEMORY 路径，不代表文件已存在；独立 PostgreSQL，应用不得直接写表。
- 已登记应用、本人身份、委托、版本共享、当前来源资格分别核验；候选不可召回。来源无法核验不等于空结果。
- 不迁移旧记忆；不凭邮箱合并身份；不以服务密钥或模型输出冒充本人。提交、生产迁移、部署及外部写入不由此计划授权。
- 完整片段处理结束一天内清除，排队和未审核候选最多 30 天，备份不超过 30 天；记忆模型调用受预算控制。
- 原生阻塞：#724。阻塞任务须 verified 且产物进入实际工作区；fixture 只能验证本票行为，不能证明真实集成完成。

## Review Focus

- `revoke_stops_new_reads`：本人撤销提交后即使通知失败，新读取也不返回该共享正文。
- `revoke_fences_inflight`：索引返回后 barrier 处撤销，再交付前重验服务授权及来源，不返回正文。
- `notification_retries_idempotently`：事务提交后模拟崩溃与发送失败，重启重试同一 notificationId；HTTP 200 无回执仍非完成。
- `receipts_cover_controlled_scopes`：回执分别记录缓存、会话或模型上下文、下游副本处理范围及逐项结果；重复回执无重复效果，错误应用拒绝。
- `cleanup_ui_states_are_evidenced`：界面区分停止共享、部分清理、未回执、无法控制和有证据范围完成；不表示已追回外发内容。
