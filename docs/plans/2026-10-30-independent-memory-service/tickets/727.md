# 后台预算与用量 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 #727 的后台预算与用量，满足下列原 Issue 全部验收。

**Architecture:** 原子预留应用和本人预算，按锁定价格及实际用量结算；未知费用持久保留并阻止重复调用。 身份、来源与任务事实由各自权威拥有；跨服务调用使用具名合同，不直接读取其他服务数据库。

**Tech Stack:** 拟建 MEMORY：Bun、Hono、PostgreSQL、React、HeroUI；测试执行器和依赖须在建库时配置。

**Spec:** [已批准 v3](../../../specs/2026-10-30-independent-memory-service-design.md) §§5–11；[ADR 0012](../../../adr/0012-independent-personal-memory-authority.md)；[合同](../contracts.md)；[MEMORY 分册](../memory.md)。

## Global Constraints

- MEMORY 和 IDENTITY 为拟建独立仓库，以下相对路径均为拟建 MEMORY 路径，不代表文件已存在；独立 PostgreSQL，应用不得直接写表。
- 已登记应用、本人身份、委托、版本共享、当前来源资格分别核验；候选不可召回。来源无法核验不等于空结果。
- 不迁移旧记忆；不凭邮箱合并身份；不以服务密钥或模型输出冒充本人。提交、生产迁移、部署及外部写入不由此计划授权。
- 完整片段处理结束一天内清除，排队和未审核候选最多 30 天，备份不超过 30 天；记忆模型调用受预算控制。
- 原生阻塞：#717。阻塞任务须 verified 且产物进入实际工作区；fixture 只能验证本票行为，不能证明真实集成完成。

## Review Focus

- `operator_budget_without_content`：运营者分别配置应用及本人预算并读取用量；其请求个人正文被拒绝。
- `atomic_reservation_limits_concurrent_calls`：并发请求竞争应用及本人上限，成功预留总额不超任一上限；按实际 microusd 结算，wire 使用十进制字符串。
- `budget_exhaustion_and_expiry`：预算不足保持 pending 并注明原因，不调用网关；受控时间到 30 天后 expired 且不能执行。
- `unknown_cost_survives_restart`：网关已调用但费用未知时预留不释放；重启和同幂等键重试不再次调用或重复记账。
- `worker_rechecks_all_gates`：重新领取时分别撤销委托、拒绝或断开来源、暂停学习、过期及预算不足；均不执行网关或形成候选。
