## Acceptance criteria

- [ ] inspect/dry-run 默认不写数据；输出脱敏来源清单、分页游标、数量/摘要、归属证据和无法迁入原因。
- [ ] 读取全部页，以稳定源身份去重；工具调用/结果、附件、时间和顺序保留，导入完成能通过原客户端读取。
- [ ] 中断后可续跑，同一数据再次导入不增重复消息；导入目标在验证前不成为活跃 writer。
- [ ] 归属不唯一、引用缺失、快照不兼容的记录隔离，不猜默认公司/本人；源/目标摘要不符阻止 verify。
- [ ] 聊天导入不导入或导出只有 Intelligence 的个人长期记忆；不重复已有外部线程归属迁移。
- [ ] 旧数据保留只读，不自动 drop 表/删除对象或卷；所有写入只在明确授权的专用 fixture 演练。
