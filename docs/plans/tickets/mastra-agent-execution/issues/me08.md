## Acceptance criteria

- [ ] 保留技能 catalog、按名称加载、支持文件读取、归档校验、刷新和撤销策略，不以空 skills 列表代替服务故障。
- [ ] 每个外层运行获取一次经校验快照；合法恢复使用绑定内容版本，同时核对当前撤销和授权。
- [ ] 技能工具保留原名称和保留名规则，外部同名工具不能覆盖学习工具或扩大文件读取范围。
- [ ] 学习 disabled 时不在启动、模块导入或运行中构造/调用 Intelligence 客户端；enabled 时使用独立配置并显示真实 delivery/health。
- [ ] 单个用户取消等待不取消另一运行共享刷新；同 Bot 不同公司/团队用户不共用未授权缓存。
- [ ] 旧学习服务异常保持已定义失败/降级策略并可观察，不静默关闭功能、不把技能目录内容写入全局可见上下文。
