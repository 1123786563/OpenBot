## Consumes / Produces

- Consumes：直接依赖票的已验证并集成 Interface、当前公开 wire、对应原功能合同与现有数据事实；不能引用另一票的私有 store。
- Produces：availableTools/connect/prepareAction/execute/receipt 业务合同；内部凭据保管与 Composio/OpenConnector/MCP Adapter。
- 全部 Interface 必须定义输入/结果、当前资格、幂等键、版本、事务/锁与超时/未知结果行为；供应商类型与秘密保留内部。

## 验收标准

- [ ] 连接可见、已连接、已授权可执行分别表达
- [ ] 秘密读取绑定用途和来源，不经公共 DTO/模型/普通日志
- [ ] 工具使用资格和环境连接资格分开，撤销阻断后续敏感动作
- [ ] 供应商差异留在 Adapter；不新增 provider 或未批准动作
- [ ] 目标工具入口迁移完整，不能通过直接 broker 调用绕过动作规则

## 验证与失败处理

未连接/撤权/错误凭据用途、供应商失败、输出脱敏和环境旧能力；原协议合同回归。

优先复用匹配当前代码的有效证据，再补缺失的 Interface 行为/真实集成验证。回退保持单一写入者与稳定持久事实；未知副作用或费用不能为回退而删除/释放。不能验证的场景明确报告阻塞；完成前修复真实有效 critical/high/medium finding。
