# MOD23：隔离可选 Learning 并整理 toolkit 的真实共享 Seam

根架构 Issue：https://github.com/1123786563/OpenBot/issues/620。阶段：第四批：扩展。本票覆盖：AR03/AR08；ADR 0010；不另做学习算法替换。

## 目标与范围

保留 Learning 独立语义，让受验证 Skill 快照通过窄内部合同供运行和包使用；清点 toolkit 的真实复用与 CopilotKit 私有协议 Adapter。

本票不新增业务功能、不替代已存在的功能 Issue；优先封装当前已启用行为。接口内部调整保持现有对外合同。

## Consumes / Produces

- Consumes：直接依赖票的已验证并集成 Interface、当前公开 wire、对应原功能合同与现有数据事实；不能引用另一票的私有 store。
- Produces：可选 SkillProvider/固定 Skill 快照合同；已用共享能力与具名历史 Adapter 清单。
- 全部 Interface 必须定义输入/结果、当前资格、幂等键、版本、事务/锁与超时/未知结果行为；供应商类型与秘密保留内部。

## 验收标准

- [ ] 学习关闭时无新增 Intelligence 强制依赖，启用失败不能伪造技能成功
- [ ] Skill 审核/归档/来源与版本规则保持，不合并为个人记忆
- [ ] 包和引擎消费固定快照，不直接依赖供应商私有方法
- [ ] 只有实际消费者迁移后才删除历史 Adapter，不为“可插拔”预建无用抽象

## 验证与失败处理

学习禁用/启用失败、撤权与固定版本、缺 Intelligence 的实际启动和已用 headless/技能路径。

优先复用匹配当前代码的有效证据，再补缺失的 Interface 行为/真实集成验证。回退保持单一写入者与稳定持久事实；未知副作用或费用不能为回退而删除/释放。不能验证的场景明确报告阻塞；完成前修复真实有效 critical/high/medium finding。
