## Consumes / Produces

- Consumes：直接依赖票的已验证并集成 Interface、当前公开 wire、对应原功能合同与现有数据事实；不能引用另一票的私有 store。
- Produces：preview/install/changeVersion/disable/remove/pin Interface；内部 SkillProvider 合同与单写资源链接。
- 全部 Interface 必须定义输入/结果、当前资格、幂等键、版本、事务/锁与超时/未知结果行为；供应商类型与秘密保留内部。

## 验收标准

- [ ] 重复安装收敛，部分失败保留操作记录而非假成功
- [ ] Bot/工具实体由其所有者创建，包仅保存链接与版本
- [ ] 升级/回滚不修改在途 pin，停用/安全撤回按合同阻断新动作
- [ ] 卸载保留用户资产，重装不绕过未知外部效果
- [ ] 不实现 #459 未来尚未启用能力，不恢复任意可执行插件

## 验证与失败处理

固定 revision、重复请求、部分失败、升级旧 Run、撤回/卸载与资产保留；复用包树有效证据。

优先复用匹配当前代码的有效证据，再补缺失的 Interface 行为/真实集成验证。回退保持单一写入者与稳定持久事实；未知副作用或费用不能为回退而删除/释放。不能验证的场景明确报告阻塞；完成前修复真实有效 critical/high/medium finding。
