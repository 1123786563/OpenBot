- 发放后用户页面可见新 Grant；组 02 缝合点：个人余额从发放到展示端到端可演示

## Implementation steps

1. 新增管理员发放路由：解析目标用户账户 → 生成幂等键 → 调用 grantCredits
2. 写入审计记录，包含操作者与目标账户
3. 在管理员界面加入发放入口，展示结果与失败原因
4. 确认发放不影响其他账户，且不修改现有部署级记录
5. 先写失败测试：重复提交幂等、越权发放拒绝、审计存在、甲乙隔离

- 本 Ticket 是业务完整切片，接口、数据库变更、授权、必要用户/管理状态和行为测试同时完成；只修改本切片涉及模块，不能顺便实施其他 Ticket。
- 领取前核验 Blocked by 各任务已验证并集成到当前工作区，读取其实际交付契约；依赖未完成不造假桩冒充已集成。任务内 provider fake 仅为测试，不得成为生产降级。
