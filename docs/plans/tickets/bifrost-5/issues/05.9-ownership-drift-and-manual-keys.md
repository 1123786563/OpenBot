## Implementation steps

1. 定义关键字段漂移（归属 Customer、授权范围、期限）与告警条件
2. 漂移时暂停该授权的发放与续期，并记录可审计事件
3. 对网关侧手工创建的 Key 明确不接管：不建立映射、不授予权限
4. 确认未接管 Key 的调用仍受准入约束（由 07.x 保证，此处只留断言）
5. 先写失败测试：归属漂移触发暂停与告警；手工 Key 不产生授权
