# 按个人用户归属积分，按 Bot 授权隔离模型凭据

OpenBot 用户是个人模型授权路径的消费与积分余额归属主体，每个“用户 × Bot 授权”分别发放有有效期的 Bifrost 虚拟 Key，所有个人 Key 共同消费同一用户余额。首次模型调用或授权时按需创建关联治理主体，不要求该主体具备 Bifrost 登录身份。公司工作台按 ADR 0004 使用独立公司账户；个人 Key 不授予公司内容权限，余额不足不切换付款方。用户于 2026-10-14 在 to-spec 阶段明确确认采用该跨 Spec 归属规则。

外部 Bot 从 OpenBot 获取凭据和模型信息后直接调用 Bifrost。这允许独立撤销某个 Bot 的访问并区分消费来源，但使 OpenBot 现有模型调用门控无法覆盖直连请求；严格防超支采用 ADR 0003 确认的同步共享预留与可靠结算，不能用原生周期预算替代个人积分余额。

拒绝的替代方案是所有用户共享部署余额、每用户所有 Bot 共用一个 Key，以及每个 Key 复制用户的全部积分额度。前两者无法满足用户确认的个人归属和独立撤销，后者会重复授予可消费额度。

依据：`docs/specs/2026-10-14-bifrost-integration-design.md` 中用户确认的 Q1–Q9，完整 Spec 已于 2026-10-14 获用户最终确认。本 ADR 记录身份、凭据粒度及调用路径；实施另按批准 Spec 与后续计划执行。
