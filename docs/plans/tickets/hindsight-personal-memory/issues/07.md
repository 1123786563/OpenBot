## What to build
用户确认或编辑个人记忆后，索引状态可靠可见；失败可恢复，旧任务不能覆盖新内容。

## Acceptance criteria
- [ ] 确认、编辑与待同步状态在 OpenBot 持久记录；只有已确认且当前有权的内容被送往 Hindsight。
- [ ] 重复任务、旧编辑任务和暂时远端失败不会产生错误的活跃版本；恢复后自动补同步。
- [ ] 界面或状态接口不把待同步或失败内容标成“已索引”；来源和租户归属在任务重试时重新核实。
