## What to build
同一自托管服务中，公司和用户的个人记忆 bank 只允许可信的服务端身份访问。

## Acceptance criteria
- [ ] OpenBot 从可信会话或持久后台任务取得公司、用户及授权范围；客户端不能提交可生效的 bank ID 或伪造作用域。

- [ ] 同一全局用户在两家公司拥有不同隔离范围；tag 或共享/无 tag 观察不能绕过 bank 权限。
