## What to build
用户能确认、编辑或拒绝派生判断，Bot 只使用本人已采纳的判断。

## Acceptance criteria
- [ ] 确认或编辑后的判断可在其全部依据仍有效的范围中召回；拒绝的判断不进入 Bot 上下文。
- [ ] 审核界面展示判断文本和完整依据，修改文本不改变依据来源或扩大授权。
- [ ] 任何依据后来失权或被删除，该判断立即停止使用，即使先前已确认。
