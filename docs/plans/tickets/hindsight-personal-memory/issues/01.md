## Parent
Spec: #376

## What to build
用户在对话或授权连接来源中得到候选记忆，能查看、确认、编辑或拒绝；在本人确认前，任何 Bot 的跨会话回答都不能使用它。

## Acceptance criteria
- [ ] 自动形成或导入的内容先成为候选，显示内容、来源和观察时间；审核操作改变的是当前用户当前公司的记录。
- [ ] 未审核候选在原 Bot、其他 Bot、网页、频道、定时任务及本地 SQL 召回中均不可见，也不能作为派生判断依据。
- [ ] 用户明确要求记住普通事实时，只直接确认其明确表述的内容，不扩写额外事实；拒绝或删除的候选不再召回。

## Blocked by
None (can start immediately)

## Verification
沿用个人记忆存储集成测试与 Bot 运行测试，覆盖审核前后和 SQL 降级路径；用专用测试数据库验证，不把跳过视为通过。

## Handoff notes
优先收紧现有个人记忆模块的召回 seam；保持候选列表对本人可见与 Bot 跨会话使用两个行为分离。
事实源：父 Spec #376、仓库已批准的 Hindsight ADR、个人记忆领域术语与公司/团队多租户 Spec。只处理本票行为；前置票交付的接口以其验收结果和当前 Git 状态为准。接手前先核对前置票是否已验证并集成。完成或中断时记录变更范围、HEAD/未提交检查点、实际验证命令与结果、遗留问题；无提交授权时不要自行提交、推送或部署。
