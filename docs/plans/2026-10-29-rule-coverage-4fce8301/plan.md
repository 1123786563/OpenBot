# 规则分支覆盖测试

授权：用户要求每种情况测试一遍。范围为当前全部规则分支的覆盖评估和安全隔离测试，不提交/部署/修改真实Issue或共享协调状态。

完整档，主控串行执行。独立reviewer只读验证覆盖矩阵。

1. 固定24规则源；逐节和协议验收表生成覆盖项，列正常/拒绝/失败恢复及证据等级。
2. 核外部协调器测试隔离后运行全部现有测试/验收样例；补充针对当前合同的反例测试，真实缺陷不因测试套件绿灯放行。
3. 对真实GitHub只读摄取/分页/关系、当前工具可用性和CI能力核验；对写入/清理使用临时本地仓库/受控输入，不改变用户远端资源。
4. 逐条区分实际运行、静态/场景核验、失败及外部阻塞，独立审查证据，不将模拟称作端到端真实任务通过。

失败处理：测试失败留报告及复现，不混入修复授权；能力不足列明受阻分支，继续其余可独立测试。测试仅用独占临时目录，不对真实协调根执行transaction。
