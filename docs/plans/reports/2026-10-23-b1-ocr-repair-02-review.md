## Finding

### HIGH — R2A regeneration removes existing driven suites and isolation metadata

- **Affected file/symbol:** `docs/verification/e2e-bun-suites.json`; generation path `scripts/e2e-bun-manifest.mjs:39–86`, consumed by `tests/bun-suites.test.ts:51–98`.
- **Evidence:** At review time, `git show HEAD:docs/verification/e2e-bun-suites.json` contained 461 driven files, 35 groups, and `directoryIslands` for both multitenancy suite families. The R2A output contained 231 files, 11 groups, and no `directoryIslands`. All 231 removed file paths still exist. Of those, 125 are absent from the archived per-file audit used for regeneration; 105 were marked `collected` in that audit and one was marked `error`. The generator replaces the entire manifest from that audit and groups only by the first two path segments. It does not preserve the `ISLANDS`/`DIRECTORY_ISLANDS` partition from `scripts/lib/e2e-manifest.mjs`. For example, the former `app/tests/ai-observability`, `app/tests/multitenancy`, `server/tests/billing-credits-writer`, `server/tests/gateway-probe`, and `server/tests/multitenancy` groups disappeared. The focused R2A driven run selected only `app/tests`, so it did not exercise these losses. The coverage audit's zero-gap result does not prove Node collection: `scripts/e2e-coverage-audit.mjs:63–85` labels any unlisted file importing `bun-test-compat` as native without reading its collection result.
- **Impact:** Previously driven suites can be sent to Node despite unknown or known Bun runtime requirements. The multitenancy driver also loses its `MT_TEST_DATABASE_URL` routing because `tests/bun-suites.test.ts` defaults missing `directoryIslands` to `[]`. This violates ADR 0008's complete, exact-once runner partition and risks collection failures or invalid environment results outside the focused app group.
- **Smallest defensible correction:** Restore the R2A PRE driven manifest and append this one proven Bun-runtime suite exactly once to its `files` and `app/tests` group, preserving all existing files, groups, causes, and `directoryIslands`. Preserve the exact collection-error audit entry. Then check the manifest set difference is exactly the new suite and recheck coverage and affected driven groups. A separate generator repair can later reconcile the full current corpus without silently replacing established partition decisions.
