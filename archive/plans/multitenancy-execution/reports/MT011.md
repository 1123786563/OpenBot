## 1. 设计要点

### 1.1 集中语义（新文件 `server/src/enterprise/tenancy/not-found-semantics.ts` §1）

not-found 判定从此只有一处定义：

- **canonical 实例**：`notFoundVerdict()` 返回冻结的
  `{ outcome: "deny", code: "RESOURCE_NOT_FOUND" }`；`isResourceNotFoundVerdict`
  是**严格**结构守卫（恰两字段、恰这两值——多带一个解释字段的形状一律拒绝，
  拒绝原因不得借形状外泄）；`serializeNotFoundVerdict` 输出确定性字节
  `{"outcome":"deny","code":"RESOURCE_NOT_FOUND"}`，非 canonical 形状响亮拒绝
  （`NOT_FOUND_VERDICT_REQUIRED`）。
- **集中 HTTP 面**：`NOT_FOUND_HTTP_STATUS = 404` + `notFoundErrorBody()`
  （`{"error":"RESOURCE_NOT_FOUND"}`，与既有路由错误体形状逐字节一致）+
  `notFoundHttpResponse()`——错误文本、状态码、错误体全部署名一处。
- **共享测试钉死闭环复用（票面验收 4）**：`not-found-semantics.test.ts` 的
  共享不变量套件把三个冻结闭环（MT008/MT009/MT010）的全部
  RESOURCE_NOT_FOUND 拒绝逐例跑过 canonical 断言（字节一致 + HTTP 面一致）。
  闭环代码零改动——它们已经与集中语义逐字节一致，这是 reuse-compatibility
  证明；下游接线票只管调用。

### 1.2 列表/游标/批量面（同文件 §2，`createResourceInventoryService`）

- **授权语义只有一处**：逐行事实组装成与 MT008 `decide()` 同一形状的
  `ResourcePolicyFacts`，经**同一注册表**求值（缺省已发布注册表，可注入）；
  版本解析 = 显式覆盖 ?? 资源所属租户 `policy_revision`，与 decide() 逐字面
  一致——「列表即 decide 的复数形状，不多不少」。公司级成员资格不在逐行
  事实内（decide 亦然），团队公共门/授权门/跨公司防线全部继承注册表。
- **列表与计数（验收 2）**：候选行按 `(created_at, id)` 全序一次受限读取
  （RLS 先行隐藏跨公司行；租户/团队比对是第二道防线），逐行经注册表求值
  后**只保留 allow**——不可见对象不进列表、不进计数。
- **keyset 游标不偏移**：游标是服务自发的 opaque base64url 令牌
  `{v:1, at, id}`，只钉在**最后一个可见项**的键上；第 limit+1 个可见项只
  用来签发下一页游标。不可见对象既不消耗页位、不产生页边界位移，也不会
  在其键大于全部可见项时制造末页游标（`nextCursor=null`）。时间戳以
  PostgreSQL `timestamptz::text` 往返（微秒无损），谓词
  `(created_at, id) > ($1::timestamptz, $2)` 行比较。中途撤销/删除不引起
  移位或错误（用例：翻页中途软删可见项，后续页原样续读）。
- **批量面（验收 3）**：`resolveResourceBatch` 一次 in-list 受限读取取回全部
  事实，逐 id 判定与输入顺序一致；一切拒绝（不存在/跨公司/跨团队/无授权/
  已删除/未发布）输出**同一** canonical 条目——逐字节同形、可相互替换；
  不存在聚合成功/失败计数、不存在短路。资源键共享锁去重 + 字典序排列，
  保持与 decide() 同键族同键序（对不存在 id 照常取锁——语句路径不按存在性
  分叉）。
- **时延的结构性代理（验收 1）**：确定性语句计数代理（测试支持文件内，
  包装后经**真实 `verifyDataDatabase`** 验证进入 WeakSet，冻结模块的
  `assertDataDatabase` 照常接受）证明：decide 缺失 vs 无权、批量全缺 vs
  全禁，SQL 语句数逐条相等——不存在按存在性分叉的语句路径。这是结构
  保证，不是墙钟测量（见 D7）。
- 事务纪律与 MT008 判定入口完全一致：`assertTrustedScope` → read committed
  + lock/statement timeout → 事务本地 `set_config('app.*')` → advisory 共享
  锁（tenant → principal → membership → workspace-membership → [resource]）。
  输入校验响亮：`INVENTORY_LIMIT_INVALID`（1..200，缺省 50）、
  `INVENTORY_CURSOR_INVALID`、`INVENTORY_BATCH_INPUT_INVALID`（≤100，空批=
  空结果）。
