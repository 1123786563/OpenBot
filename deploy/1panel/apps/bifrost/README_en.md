## Introduction

OpenBot Bifrost for OpenBot. See the OpenBot 1Panel deployment guide for dependencies and configuration.

## Database

Select a database instance managed by 1Panel. The form generates a database name, user, and password. 1Panel uses these values to create the database and its dedicated user. To reuse a registered database, enter its current credentials.

Prepare a dedicated Bifrost database and role. The registry proxy continues to serve Bifrost and the skill registry.
