## 产品介绍

个人记忆索引与召回。安装参数与依赖见 OpenBot 的 1Panel 部署说明。

## 数据库

应用自带一个 PostgreSQL（`pgvector/pgvector:pg17`，服务名 `postgres`，只在应用内部网络可达，数据在 `postgres-data` 数据卷），默认直接使用。库名、用户名和密码在安装参数里填写，首次启动时据此建库；修改它们不会改动已建好的库，要换凭据请重建数据卷。

也可以改用 1Panel 管理的 PostgreSQL 实例：把「PostgreSQL 主机」填成该实例的容器名。实例需提供 pgvector，且 pgvector 必须能在本机 CPU 上运行——1Panel 自带的 PostgreSQL 集群镜像里的 pgvector 是按 AVX-512 编译的，在没有 AVX-512 的机器上，一次向量写入就会让数据库后端崩溃并断开该实例上的全部连接，这种机器请保持默认的自带数据库。复用已有数据库时，请管理员在目标库执行 `CREATE EXTENSION IF NOT EXISTS vector;`。密码含 URI 特殊字符时，在「数据库密码」填原始值，再填写「URL 编码后的数据库密码」。

API 容器加入共享 1Panel 网络，供可信容器访问。

镜像已内置本地嵌入和重排模型，启动时使用 `HF_HUB_OFFLINE=1`，不访问 Hugging Face。首次启动会把这些模型复制到 `model-cache` 数据卷；若将来更换镜像版本导致模型缺失，离线模式会直接报错，需要重新准备模型缓存。

## 控制台

控制台是应用的 Web 界面，也是 1Panel 的主访问端口（`PANEL_APP_PORT_HTTP`，默认 19999），安装后点「访问」即打开控制台。API 使用独立端口 `PANEL_APP_PORT_API`（默认 18888）；OpenBot 经容器网络 `http://hindsight:8888` 调用 API，不依赖该主机端口。

控制台由安装表单中的「控制台访问密钥」保护：打开后先看到登录页，输入该密钥后才能进入，未登录时页面和控制台 API 都被拒绝。密钥在安装后可以在应用参数里修改，修改后重建应用即生效，已登录的会话随之失效。

控制台绑定宿主机回环端口。在本机打开 `http://127.0.0.1:19999`，或经反向代理访问。API 端口没有登录门禁，不要反向代理到公网；确需对外时，只反代 `/v1/` 并由调用方携带 API 密钥。
