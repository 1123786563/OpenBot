## 产品介绍

个人记忆索引与召回。安装参数与依赖见 OpenBot 的 1Panel 部署说明。

## 数据库

安装时选择 1Panel 管理的数据库实例。表单会随机填充库名、用户名和密码，1Panel 使用这些值自动建库和建用户。复用已登记的数据库时，填回原库名、用户名和密码。密码含 URI 特殊字符时，在「数据库密码」填原始值，再填写「URL 编码后的数据库密码」。

PostgreSQL 实例需提供 pgvector。复用已有数据库时，请管理员在目标库执行 `CREATE EXTENSION IF NOT EXISTS vector;`。API 容器加入共享 1Panel 网络，供可信容器访问。

## 控制台

控制台是应用的 Web 界面，也是 1Panel 的主访问端口（`PANEL_APP_PORT_HTTP`，默认 19999），安装后点「访问」即打开控制台。API 使用独立端口 `PANEL_APP_PORT_API`（默认 18888）；OpenBot 经容器网络 `http://hindsight:8888` 调用 API，不依赖该主机端口。

控制台由安装表单中的「控制台访问密钥」保护：打开后先看到登录页，输入该密钥后才能进入，未登录时页面和控制台 API 都被拒绝。密钥在安装后可以在应用参数里修改，修改后重建应用即生效，已登录的会话随之失效。

控制台绑定宿主机回环端口。在本机打开 `http://127.0.0.1:19999`，或经反向代理访问。API 端口没有登录门禁，不要反向代理到公网。
