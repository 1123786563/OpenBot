## 产品介绍

私有配置和密钥管理。安装参数与依赖见 OpenBot 的 1Panel 部署说明。

## 数据库

安装时选择 1Panel 管理的数据库实例。表单会随机填充库名、用户名和密码，1Panel 使用这些值自动建库和建用户。复用已登记的数据库时，填回原库名、用户名和密码。密码含 URI 特殊字符时，在「数据库密码」填原始值，再填写「URL 编码后的数据库密码」。

准备 Infisical 专用库和用户。迁移已有数据时使用原加密密钥。

## Redis

安装时在「已有 Redis 实例」下拉框中选择 1Panel 管理的 Redis，「Redis 密码」随所选实例自动带入，未设密码时留空。密码含 URI 特殊字符时，再填写「URL 编码后的 Redis 密码」，编码规则同数据库密码。


## 初始管理员

新装时填写管理员邮箱、密码、名字和组织名称，安装任务会创建首位管理员。密码至少 14 位。加密密钥和认证密钥留空时自动生成，请备份 `installation-secrets` 数据卷。恢复时填写原密钥，初始管理员字段可以全留空。
