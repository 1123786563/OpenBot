1. bun.lock 版本不一致：宿主 bun 1.4.2 生成的 lock 被 Docker 里钉死的 1.3.14 拒绝（frozen-lockfile）→ 用 1.3.14 容器 `bun install --lockfile-only` 重新生成（备份 /tmp/bun.lock.1.4.2.bak）
2. postgres 镜像缺 pgvector：迁移 0000 的 chunks.embedding vector(1536) 需要（0010 才删）→ docker/postgres-partman.Dockerfile 加 postgresql-17-pgvector
3. 企业角色缺失：迁移 0056/0058/0060 引用 ob_ent_* 角色 → 手工执行 server/ops/enterprise/roles.sql（正常流程 DBA 做）
